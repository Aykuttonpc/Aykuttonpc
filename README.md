## Featured Projects

### [AykutOnPC](https://github.com/Aykuttonpc/AykutOnPC) — Production Portfolio Site with AI Chat
> `ASP.NET Core MVC` `.NET 9` `PostgreSQL` `Groq Llama 3.3 70B` `Semantic Kernel` `Docker` `Nginx` `GitHub Actions`

**Live on Hetzner VPS.** Cyberpunk-themed portfolio with an AI chat widget (knowledge-base driven), admin dashboard with JWT auth, visitor analytics (GDPR-safe, SHA-256 hashed IPs with daily-rotating salt), and full CI/CD. Multi-stage Docker build, healthchecks, resource limits, Let's Encrypt, daily PG backups with rclone offsite.

### [FocusForge](https://github.com/Aykuttonpc/FocusForge) + [Voxi.Microservices](https://github.com/Aykuttonpc/Voxi.Microservices) — Android App + Backend
> `Kotlin` `Jetpack Compose` `Clean Architecture` `Room` `MVVM` `WorkManager` · `ASP.NET Core` `.NET 9` `xUnit` `Docker`

Native Android productivity app (habits, tasks, daily focus score) built with Kotlin + Compose and Clean Architecture (Data / Domain / UI, Use Cases, Repository pattern). Backed by a .NET 9 Identity microservice with integration tests (`WebApplicationFactory` + FluentAssertions) and Docker.

### [SmartCampus](https://github.com/Aykuttonpc/SmartCampus) — Real-time Campus Space Management
> `ASP.NET Core MVC` `EF Core` `SQL Server` `SignalR` `Docker` `Session Auth`

University campus occupancy tracker and reservation platform. Sensor data feeds a live dashboard; role-based system (Student / Staff / Admin) handles reservations, approvals, and cancellations. T-SQL heavy: Views, Stored Procedures, server-side pagination. Includes IDOR protection and a no-show analytics panel for admins.

### [OnlineEdu](https://github.com/Aykuttonpc/OnlineEdu) — Full-Stack E-Learning Platform
> `ASP.NET Core 8` `EF Core 8` `JWT` `AutoMapper` `FluentValidation` `Swagger` `SQL Server`

18-controller REST API with role-based authorization (Admin / Teacher / Student). N-tier architecture with Generic Repository & Service patterns. Course management, enrollments, blog, teacher profiles, and a full admin panel. Documented with Swagger.
